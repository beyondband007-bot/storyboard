## 一、产品概述

### 1.1 产品定位

分镜脚本生成器是一款面向视频制作行业的智能工具，帮助用户快速生成专业级宣传片、产品片、案例片的分镜脚本。

**核心价值**
- 从创意到成稿，效率提升80%
- 专业模板支撑，品质对标行业头部
- AI辅助创作，降低专业门槛

### 1.2 目标用户

| 用户类型 | 使用场景 | 核心诉求 |
|---------|---------|---------|
| 视频制作公司 | 提案准备、项目规划 | 快速出稿、品质保证 |
| 企业市场部 | 内部宣传片需求 | 降低沟通成本 |
| 广告代理商 | 创意提报 | 专业呈现、说服力强 |
| 独立创作者 | 个人项目规划 | 低门槛、高效率 |

### 1.3 产品形态

- **Web端应用**：浏览器访问，无需安装
- **账号体系**：支持团队协作
- **输出格式**：Markdown文件 + Word文档

## 三、核心功能模块

### 3.1 项目创建

#### 功能描述

用户创建新的分镜脚本项目，录入基础信息。

#### 功能要点

| 功能项 | 说明 |
|-------|------|
| 项目命名 | 输入项目名称，如"XX企业宣传片" |
| 项目定位 | 选择客户类型（政府/企业/消费者）+ 影片类型（宣传片/产品片/案例片/旅游片） |
| 成片要求 | 设置时长、风格基调、成片比例 |
| 项目描述 | 可选填写项目背景、特殊要求 |

#### 交互说明

1. 进入系统后，点击"新建项目"
2. 填写项目基础信息
3. 选择项目定位（影响后续模板推荐）
4. 设置成片要求
5. 保存进入下一步

---

### 3.2 内容单元管理

#### 功能描述

管理视频中的核心内容单元（产品、景点、服务等）。

#### 功能要点

| 功能项 | 说明 |
|-------|------|
| 添加单元 | 创建新的内容单元 |
| 单元命名 | 输入单元名称 |
| 核心特征 | 描述该单元的核心卖点/特征 |
| 命名口径 | 如有品牌规范，填写统一命名 |
| 排序调整 | 拖拽调整单元顺序 |
| 删除单元 | 移除不需要的单元 |

#### 交互说明

1. 在"内容规划"页面添加内容单元
2. 每个单元填写名称、核心特征、命名口径
3. 可添加多个单元
4. 支持拖拽排序

---

### 3.3 内容逻辑选择

#### 功能描述

选择视频内容的组织逻辑，系统智能推荐最优方案。

#### 功能要点

| 逻辑类型 | 适用场景 | 示例 |
|---------|---------|------|
| 空间递进 | 多地点展示 | 地面→水面→空中→地下 |
| 时间递进 | 时间流转叙事 | 清晨→正午→黄昏→夜晚 |
| 功能递进 | 功能链条展示 | 感知→决策→执行→反馈 |
| 人群递进 | 多人群覆盖 | 儿童→青年→老人→家庭 |
| 情绪递进 | 情感叙事 | 觉醒→活力→思考→展望 |
| 规模递进 | 层级递进 | 城市→社区→家庭→个人 |
| 问题解决 | 问题导向 | 问题→分析→方案→成果 |

#### 交互说明

1. 系统根据项目定位自动推荐最佳逻辑
2. 用户可查看其他选项并调整
3. 确认后进入下一步

---

### 3.4 参考样片分析（可选）

#### 功能描述

上传或选择参考样片，系统分析并提取参考要素。

#### 功能要点

| 功能项 | 说明 |
|-------|------|
| 上传样片 | 上传本地视频文件或提供链接 |
| 样片库选择 | 从系统样片库中选择参考 |
| 智能分析 | 系统分析样片风格、节奏、转场 |
| 要素提取 | 提取可参考的关键要素 |

#### 交互说明

1. 用户可选择上传样片或跳过此步
2. 若上传，系统自动分析并输出分析报告
3. 用户确认或调整分析结果

---

### 3.5 脚本生成

#### 功能描述

系统自动生成分镜脚本，支持提案版和完整版两种输出。

#### 功能要点

##### 生成模式

| 模式 | 说明 | 适用场景 |
|-----|------|---------|
| 提案版优先 | 先生成提案版，确认后再生成完整版 | 正常流程，推荐 |
| 直接完整版 | 一次性生成完整版 | 时间紧迫或需求明确 |

##### 提案版内容

| 模块 | 内容 |
|-----|------|
| 创作前提 | 项目定位、成片目标、成片价值 |
| 创意策略 | 创意理念、策略依据、差异化亮点 |
| 创意主轴 | 核心表达、情绪曲线、观众感受预期 |
| 视觉风格设定 | 画面风格、色彩体系、镜头语言、视觉符号 |
| 总旁白 | 完整旁白文案 |
| 段落文案 | 各篇章分文案 |
| 分镜脚本表 | 完整分镜表（8列标准格式） |
| 音乐音效设计 | 音乐风格、关键音效、情绪曲线 |
| 统一表达归纳 | 情绪基调、核心隐喻、视觉语言 |

##### 完整版补充内容

| 模块 | 内容 |
|-----|------|
| 拍摄方式建议 | 实拍/AIGC/混合分配、执行方式总表 |
| 交付分工建议 | 团队配置、镜头分工 |

#### 交互说明

1. 选择生成模式
2. 系统自动生成，显示进度
3. 生成完成，进入预览编辑页面
4. 用户可编辑调整各模块内容
5. 满意后进入导出流程

| 版本对比 | 对比不同版本的内容差异 |

#### 交互说明

3. 支持一键重新生成

