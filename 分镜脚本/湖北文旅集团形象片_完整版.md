## 一、创作前提

**项目定位**
- 客户类型：国有企业
- 影片类型：企业形象片（30周年庆典）

**成片目标**
- 回顾30年发展历程，展现企业深厚积淀
- 传递企业文化与核心价值观，凝聚员工认同
- 展示品牌实力与未来愿景，增强各方信心

**成片价值**
- 传达什么：湖北文旅集团30年深耕荆楚、服务人民的初心与使命
- 触达什么：员工的归属感与自豪感、合作伙伴的信任、社会的认同
- 达到什么：从"历史回顾"升华为"精神传承"，建立品牌文化资产

## 二、创意策略

**创意理念**

以"时间"为轴，以"足迹"为线索，讲述一个企业从创业初心到宏伟蓝图的30年故事。不是简单的编年史，而是精神传承的史诗。

**策略依据**
- 30周年是里程碑时刻，需要仪式感与厚重感
- 国企形象片需平衡"历史厚重"与"时代活力"
- 兼顾内部庆典与外部传播，需情感共鸣与实力展示并重

**差异化亮点**
- 双线叙事：时间线（企业发展）+ 空间线（荆楚大地）
- 以人带史：用员工/人物故事串联企业发展
- 历史与未来呼应：过去铸就现在，现在成就未来

### 创意洞察

**目标受众画像**

| 受众群体 | 核心诉求 | 情感触点 |
|---------|---------|---------|
| 老员工 | 归属感、被认可 | 回忆奋斗岁月、荣誉感 |
| 新员工 | 了解企业、认同文化 | 企业故事、精神传承 |
| 客户/伙伴 | 信任感、实力认同 | 成就展示、未来信心 |
| 政府/社会 | 责任感、贡献认同 | 社会价值、使命担当 |

**核心发现**
> 30年的意义，不在于"我们走了多远"，而在于"我们为什么出发"。
> 每一个里程碑背后，都是一群人的坚守与担当。

### 传播策略

**内容策略**
- 时间为经：四个篇章对应四个发展阶段
- 人物为纬：用人物故事点亮企业发展

**情绪策略**
- 追忆(温情) → 奋斗(燃) → 荣耀(自豪) → 憧憬(希望)

**叙事策略**
- 宏观叙事与微观故事结合
- 过去与未来呼应，形成闭环

- 启航篇：缓慢推拉、定格、历史厚重感
- 深耕篇：稳重跟拍、航拍大景、气势感

## 九、拍摄方式建议

### 9.1 执行方式分配原则

**国企30周年庆典片特点**
- 强调真实感与历史厚重感
- 人物镜头必须实拍，体现真实员工与精神面貌
- 航拍大景优先实拍，展现资源实力
- 历史资料画面需收集整理，无法拍摄部分可考虑情景再现

**分配原则**

| 内容类型 | 推荐方式 | 原因 |
|---------|---------|------|
| 老员工口述采访 | 实拍 | 真实感、情感表达 |
| 现代景区展示 | 实拍 | 品质感、资源实力 |
| 航拍大景 | 实拍 | 展现真实资源 |
| 员工工作场景 | 实拍 | 真实工作状态 |
| 历史资料画面 | 收集整理 | 企业档案、新闻资料 |
| 早期创业场景 | 情景再现/模拟 | 无历史影像时的补充方案 |
| 数据可视化动画 | 后期制作 | 信息清晰、视觉美观 |
| Logo演绎 | 后期制作 | 品牌规范、精度要求高 |
